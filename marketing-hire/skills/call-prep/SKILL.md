# Call prep

This is a worker draft for one meeting.

Read the product brief, the icp file, the account brief if the task names that company, and the battlecard if a competitor is likely. Return: what we already know, what is still unknown, five questions in the buyer's words, and the one thing we hope they say. The first ten minutes are questions, not a pitch.

Do not invent attendees, budget, or a prior conversation. Apply the content-editor skill.
