# Content library

These sheets are the shape of a draft. They are not a second voice. Read the one file the assignment names. Do not read the rest.

- `x.md` — a post or short thread on X
- `linkedin.md` — a LinkedIn post
- `long-form.md` — an essay, a newsletter, or a long thread
- `comedy.md` — only when the humor dial is above zero
- `launch-x.md` — the launch thread
- `launch-linkedin.md` — the launch post
- `launch-video.md` — the short launch script

Paths are under `/opt/plow/skills/content-library/`. Pillars and channel voice still come first.
