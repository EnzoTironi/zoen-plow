# Replies to our posts

Someone already commented, quote-posted, or replied. This is not the reply-guy queue, which goes looking for other people's posts.

This is a worker draft when there are several comments. One comment can stay in the turn. Read the pillars, the channel voice, and the X or LinkedIn sheet for the channel they named.

Each reply names something in that comment. It does not say "great post" or "totally agree". A quote-post adds one new idea.

If the comment text is missing, say so and stop. Do not invent the comment. Apply the content-editor skill. Follow the marketing-delivery skill before a reply is sent. With yolo off, the batch waits.
