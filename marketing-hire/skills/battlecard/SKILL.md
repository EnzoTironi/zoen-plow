# Battlecard

The pages live in `/var/lib/plow/workspace/battlecards.md`. Only the owner writes them, in the owner's conversation. This stays in the turn.

Ask which competitor, including the spreadsheet or the habit people use instead of a product. One page each, starting with the one they lose to. Each page has: who that option is best for, one honest strength, one honest weakness, the price only if the owner knows it, and three sentences they can say when asked why us. Unknown stays unknown. Do not invent a review, a price, or a weakness.

Add one question the owner can ask a buyer that shows the gap without naming the competitor.

When a later draft mentions that competitor, read this file. Trash talk loses to the page.
