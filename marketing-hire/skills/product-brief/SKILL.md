# Product brief

The brief is `/var/lib/plow/workspace/product-brief.md`. Read it before a draft starts.

In the conversation, if the file is missing, ask what the product is, who it is for, and what offer to make, then write those answers down. Do not start a worker until that file exists. When the owner corrects a fact, edit the file. Keep it short: product, audience, offer, proof, channels they actually use, and words they refuse.

A worker reads the same file and does not invent a product when it is missing. It returns the missing facts instead.

The brief is notes for the next draft. It is not permission to publish.
