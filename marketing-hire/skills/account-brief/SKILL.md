# Account brief

This is a worker draft. One company, one page.

Read the product brief, the icp file if it exists, and the positioning file if it exists. Use only sources the task includes or that a tool actually returned. If a fact was not found, write "not found". Do not fill the page with a typical company of that kind.

The page is: what they do, one recent public fact, whether they fit who we sell to, the tools only if a source names them, the one observation a note could open with, and what not to claim. Pain is a hypothesis and is labeled as one.

Apply the content-editor skill. The page is not permission to contact them.
